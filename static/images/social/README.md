# Social icons

These SVG assets are standalone, monochrome and usable as CSS masks.

- `github.svg`, `rss.svg`, `mail.svg`, `douyin.svg`, `x.svg`, `zhihu.svg` were extracted from the existing `zhouxin/zhouxin-space/themes/PaperMod/layouts/_partials/svg.html` before project cleanup. `douyin.svg` uses PaperMod's `tiktok` musical-note glyph. The mail viewport was normalised to 24 × 24 to avoid clipping. PaperMod's MIT notice is retained in `LICENSE-PaperMod.txt`.
- The pre-existing Xiaohongshu React SVG was extracted from `nextjs-blog-template/src/components/icons/xiaohongshu.tsx` and preserved verbatim apart from removal of JSX attributes in `archive/xiaohongshu-template.svg`.
- The active `xiaohongshu.svg` is the standalone SVG from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/xiaohongshu.svg), retrieved 2026-11-16. Its CC0 1.0 notice is retained in `LICENSE-SimpleIcons.md`. This allows the homepage to use a documented upstream SVG while retaining the original project asset.

The marks identify their respective services. Social account destinations are configured separately in the homepage data.
